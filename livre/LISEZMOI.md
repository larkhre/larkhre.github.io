# Le livre

*Apprends à coder de zéro avec Larkhré*, édition 1.1.

```
python3 livre/fabrique.py
```

Le script exécute **chaque exemple du livre** avec `larkhre.py`, s'arrête si l'un d'eux ne se
comporte pas comme prévu ou dépasse la largeur de la page, puis fabrique le PDF. Les résultats
« À l'écran » sont ceux que le moteur affiche réellement. Pour modifier le livre, change
`contenu.py` et relance. Nécessite `pip install reportlab`.
